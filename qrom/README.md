# qrom

Unary-iteration QROM (Babbush et al. 2018) and SELECT-SWAP with clean or borrowed workspace, as ISA 0.9
objects with certificates in `objects/`, generated by `adders/generate.py`. A table is part of an object's
identity, so `objects/` holds sample tables; a consumer generates its own table's object.

Plan, formulas, consumers and contract gaps: [`docs/circuits-port.md`](../docs/circuits-port.md). Tests: `tests/circuits/run`.
